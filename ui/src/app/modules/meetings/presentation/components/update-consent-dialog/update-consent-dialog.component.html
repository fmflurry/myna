Check for updates?

Myna does everything on this Mac. Recording, transcription and summaries never leave it, and nothing is sent anywhere by default.

Update checks are the one exception, and they are off until you turn them on.

If you turn them on, once a day Myna asks GitHub whether a newer version of Myna exists. That request sends:

  • your IP address, to github.com (and to objects.githubusercontent.com, which it redirects to)
  • nothing else — no meeting audio, no transcripts, no summaries, no usage statistics, no identifier, no account

Your version number isn't sent either. Myna downloads the same public file every user downloads and compares versions here on your Mac.

Myna will only tell you an update exists. It will never download or install one on its own.
